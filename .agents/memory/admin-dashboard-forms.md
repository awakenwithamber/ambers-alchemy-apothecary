# Admin dashboard & form capture

Decision: capture all orders AND site form submissions to Supabase and view them in an
in-app admin dashboard at `/admin`, rather than emailing them or relying on Zapier.

**Why:** order/lead data already lives in Supabase; a dashboard is more reliable than
email/Zapier (which require external account setup) and gives one place to see everything.

**How to apply:**
- Site forms (contact, consultation, soap-order, order, email-capture) POST to
  `/api/form-submit` (was the Zapier `form-relay`). They are stored in the
  `form_submissions` table. The legacy `/.netlify/functions/form-relay` path still works
  (routes to the same handler) for backwards compat.
- Zapier forwarding is OPTIONAL: only fires if a `ZAPIER_<TYPE>_WEBHOOK` env var is set.
  No webhook configured = data still saved; nothing breaks. Zapier URLs can only be
  generated by the site owner inside their own Zapier account.
- Admin auth: `POST /api/admin/login` checks `ADMIN_PASSWORD` and issues a JWT signed with
  `GRIMOIRE_JWT_SECRET`. Protected `/api/admin/*` read endpoints accept the token ONLY via
  `Authorization: Bearer` or `x-admin-token` header — never a query param (token leakage).
