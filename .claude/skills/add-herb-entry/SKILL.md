# Add a herb entry (public library)
Content comes from Amber or sources she supplies. Never invent properties, dosages, interactions, or citations.

Entry fields: common name, botanical name, family, parts used, preparation forms, **Traditional use**, **Established evidence** (only with a verified source URL), **Preliminary evidence**, **Amber's experience** (her words), **Safety & interactions** (pregnancy/nursing, medications, allergies, contraindications — always public), related products, related Grimoire entries (public metadata only), sources.
Wording: "traditionally used to support…". No disease claims. If the herb appears in a supplement product, add the FDA disclaimer beside any benefit statement.
Then: unique route + meta + canonical + BreadcrumbList/Article JSON-LD, add to search index and sitemap, herb count re-renders from the dataset, `compliance-reviewer`, `release-gate`.
